# Code of Conduct

Tulpar is a project for building communication infrastructure. Participants are expected to be direct, respectful, and constructive.

## Expected behavior

- Discuss ideas and code, not people.
- Give actionable technical feedback.
- Respect privacy and never publish another person's private data, credentials, messages, or server details.
- Follow the security disclosure process in [SECURITY.md](SECURITY.md).
- Assume good faith while still requiring evidence for claims.
- Help keep discussions accessible to contributors with different levels of experience.

## Unacceptable behavior

- Harassment, threats, discrimination, or personal attacks.
- Doxxing or publishing private information without consent.
- Sharing secrets, private messages, or production data.
- Deliberately disruptive behavior, spam, or bad-faith security testing.
- Using the project to build or operate surveillance, malware, or abuse infrastructure.

## Enforcement

Maintainers may edit, remove, or reject contributions and participation that violate these rules. Serious or repeated violations may result in a ban from project spaces.

Report conduct issues privately to the project owner through the same private channel used for security reports. Do not publish sensitive details in a public issue.

This is a small, evolving policy. It will be expanded with a formal enforcement process before the first public release.
