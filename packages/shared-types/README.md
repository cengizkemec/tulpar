# @tulpar/shared-types

Generated OpenAPI types for Tulpar clients and SDKs.

- `openapi.json` is the checked-in contract snapshot from the running server.
- `src/schema.d.ts` is generated by `openapi-typescript`.
- Do not hand-edit `src/schema.d.ts`.

Regenerate after an API contract change:

```bash
pnpm generate:types
pnpm typecheck
```

In CI, the same commands must pass and the generated file must match the checked-in snapshot.
