# Security policy

The full security model, threat model, and secure-development rules are in [docs/SECURITY.md](docs/SECURITY.md).

## Reporting a vulnerability

Do not open a public issue, discussion, or pull request for a suspected vulnerability.

The private security contact has not been finalized yet. Until a dedicated address and GitHub Security Advisories configuration are announced:

- Contact the project owner through a private channel.
- Include the affected component, version or commit, reproduction steps, impact, and any suggested mitigation.
- Do not access other users' data, disrupt a running instance, or publish details before a fix is available.

The reporting process will be formalized before the first public release.
